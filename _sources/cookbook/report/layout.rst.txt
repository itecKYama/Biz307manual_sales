================================================
帳票レイアウトを使い分けるためのマスタを設定する
================================================

標準のレイアウトとは別に、独自に追加したレイアウトを指定して帳票を出力できるようにします。

レイアウトを指定できる帳票は、以下となります。

  * 見積書
  * 見積書(控)
  * 出荷案内書（出荷）
  * 出荷案内書（出荷指示）
  * 送り状
  * 納品書
  * 領収書
  * 注文書
  * まとめ注文書

.. _SMS_cookbook_report_layout-prepare:

前提条件
========
* 帳票レイアウトファイルを帳票サーバーに配置していること。

  フレキシブルレポートを利用してレイアウトを作成した場合には、帳票レイアウトファイルを帳票サーバーに配置する必要はありません。


.. _SMS_cookbook_report_layout-do:

実行手順
========

1. 帳票設定の登録
  
  追加したレイアウトに対して帳票設定を登録します。

  * メニュー ::

      Biz∫ APF
        システム管理
          帳票設定
            帳票設定

  * 設定内容
  
    以下の表にしたがい、各項目に値を設定してください。
  
    .. list-table::
       :widths: 1, 2, 4
       :header-rows: 1

       * - 項目
         - 設定値
         - 備考
       * - アプリケーションID
         - sms
         - アプリケーションIDを間違えると、印刷実行ダイアログで検索対象となりません。
       * - モジュールID
         - 見積書： es
           見積書(控)： es
           出荷案内書（出荷）： sa
           出荷案内書（出荷指示）： si
           送り状： sa
           納品書： sa
           領収書： sa
           注文書： bu
           まとめ注文書： bu
         - モジュールIDを間違えると、印刷実行ダイアログで検索対象となりません。
       * - 帳票コード
         - 任意
         - 
       * - 製品区分
         - SVF For PDF
         -
       * - 帳票レイアウトファイルパス
         - 任意
         - 帳票サーバに配置したレイアウトファイルのファイルパス
         
           フレキシブルレポートを利用してレイアウトを作成した場合には、設定する必要はありません。
       * - 帳票ファイル表示名
         - 任意
         - 帳票ファイル表示名は、以下の場面で表示されます。
         
           * 印刷実行ダイアログでレイアウトを選択するときの帳票ファイル表示名
            
           * ファイルダウンロードダイアログのファイル名
         
           例） XXX社用見積書

       * - 削除フラグ
         - 活動中
         -

    
  .. note::

    フレキシブルレポートを利用してレイアウトを作成した場合は、  |BAPF| のフレキシブルレポート `フレキシブルレポート決定表`_ [#partner_apf]_ を参照してフレキシブルレポート決定表を登録してください。


2. 帳票グループ関連の登録

  追加したレイアウトと帳票グループの関連付けを登録します。以下のメニューから帳票グループを選択し、帳票グループ関連を追加します。

  * メニュー ::

      Biz∫ APF
        システム管理
          帳票設定
            帳票グループ管理

  * 帳票グループ

    以下の表にしたがい、帳票グループを選択してください。
  
    .. list-table::
       :widths: 2, 2, 2
       :header-rows: 1

       * - 帳票
         - 帳票グループコード
         - 帳票グループ名
       * - 見積書
         - ESR0010
         - 見積書
       * - 見積書(控)
         - ESR0010
         - 見積書
       * - 出荷案内書（出荷）
         - SHR0060
         - 出荷案内書（出荷）
       * - 出荷案内書（出荷指示）
         - SIR0030
         - 出荷案内書（出荷指示）
       * - 送り状
         - GTR0020
         - 送り状
       * - 納品書
         - SLR0020
         - 納品書
       * - 領収書
         - SLR0040
         - 領収書
       * - 注文書
         - ORR0020
         - 注文書
       * - まとめ注文書
         - ORR0050
         - まとめ注文書

  * 帳票グループ関連の設定内容
  
    以下の表にしたがい、各項目に値を設定してください。
  
    .. list-table::
       :widths: 1, 2, 4
       :header-rows: 1

       * - 項目
         - 設定値
         - 備考
       * - 帳票設定ID
         - 1で登録した帳票レイアウトの帳票設定ID
         - 帳票コード、帳票ファイル表示名から対象を判定します。
       * - ソートキー
         - 任意
         - 印刷実行ダイアログでレイアウトを選択するときに、ソートキーの昇順で表示されます。
       * - デフォルトフラグ
         - 任意
         - デフォルトにすることで、印刷実行ダイアログの項目「帳票レイアウト」に初期表示される値となります。

3. 取引先別帳票レイアウト決定表の登録

  取引先毎に各帳票のレイアウトをあらかじめ指定したい場合のみ、取引先別帳票レイアウト決定表を登録します。

  取引先別帳票レイアウト決定表の登録につきましては、  |BAPF| の取引先マスタ拡張 モジュール `取引先別に帳票レイアウトを設定する`_ [#partner_apf]_ を参照してください。


.. [#partner_apf] Biz∫パートナーサイトに接続します。

4. 会社パラメータの設定

  帳票出力時に追加したレイアウトで出力するためには会社パラメータ「帳票レイアウト区分」を設定する必要があります。
  印刷時に指定した帳票レイアウトで印刷する場合は、"1"(選択)を設定してください。
  取引先別に出力する帳票レイアウトを変更したい場合は、"2"(取引先別)を設定してください。

  帳票出力に関わる会社パラメータの設定は、ビジネスルール `『 46帳票について 』`_ [#partner_sms]_ および、 `『 01_コード値・システムパラメータ一覧 』`_ [#partner_sms]_ を参照してください。

.. [#partner_sms] Biz∫パートナーサイトに接続します。

.. _SMS_cookbook_report_layout-endConditions:

完了条件
========
該当の帳票出力画面にて、追加したレイアウトを指定して帳票出力できることを確認します。
